# return.to_thread

```
return.to_thread {
  revision   := tested commit and worktree state
  change     := cohesive diff or PR
  checks     := individual results and execution records
  artifacts  := screenshots, recordings, logs and traces
  limits     := uncovered cases, blockers and uncertainty
  decisions  := unresolved product or release questions
  next_action := responsible owner and required action

  RETURN the result for the original thread
  SEND messages only when that action is authorized
  FOLLOW repository review and merge policy
}
```
