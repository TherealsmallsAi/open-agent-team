# authority.resolve

```
authority.resolve {
  IDENTIFY requester from authorized context
  READ repository rules and source-thread decisions
  RESOLVE permitted actions, targets and required approvals
  CHECK host tools and actual access
  KEEP unresolved authority explicit

  ASSERT understanding != authorization
  ASSERT passing_checks != release_approval
  REUSE existing grants without asking for them again
}
```

Understanding the code does not grant permission to change it.  
Passing tests does not grant permission to merge or deploy.
