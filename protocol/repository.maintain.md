# repository.maintain

```
repository.maintain {
  FIND repeated corrections and obsolete implementation examples
  ENCODE stable requirements in APIs or automated checks
  MAKE diagnostics identify the violation and supported recovery
  VERIFY the constraint catches the original failure
  VERIFY permitted behavior still succeeds
  MIGRATE obsolete examples
  PRESERVE useful design rationale
  AVOID unrelated redesign driven by broad model critique
}
```

Turn the same human correction into a permanent, automatic check whenever practical.
